## CN2 GIA 到底值不值得为它多花钱

先把这个问题说清楚，不然后面看套餐会一头雾水。

香港到大陆的线路大致分三档：普通直连、CN2 GT、CN2 GIA。普通直连晚高峰基本废了；CN2 GT 好一些，但共享用户多，高峰期也会抖；CN2 GIA 是电信最高优先级的回程线路，绕的跳数少，QoS 优先级高，同等网络压力下表现明显更稳。

代价是贵。同配置下，CN2 GIA 的香港节点通常比普通线路贵 30% 到一倍不止。

值不值，看你用来干什么。跑个人博客、低频访问的工具，普通线路够了。要做实时业务、跑代理、或者对延迟敏感的应用，GIA 的溢价是实打实花在刀刃上的。
